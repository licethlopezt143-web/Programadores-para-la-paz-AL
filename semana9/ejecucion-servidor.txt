Al ejecutar node server.js, se inicia el servidor web creado con Node.js.

En la terminal aparece el mensaje:

Servidor ejecutándose en puerto 3000

Esto indica que el servidor está activo y listo para recibir solicitudes.

Cuando se visita la ruta /estado desde el navegador, el servidor responde indicando que está funcionando correctamente. Esto permite verificar que la aplicación está activa y disponible para los usuarios.
